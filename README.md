# Mai Anh Duc — Portfolio

Personal portfolio for Mai Anh Đức, an Information Technology undergraduate at the Posts and Telecommunications Institute of Technology (PTIT), Vietnam. The content presents a software engineering foundation and a current focus on Data Science and AI.

The existing React template's layout, typography, gradients, theme toggle, responsive navigation, and animations are retained.

## Local development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```
